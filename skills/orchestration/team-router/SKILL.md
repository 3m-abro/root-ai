# Team Router

## Purpose

Route work to the correct portfolio team and shared department.

## Procedure

For every substantial task:

1. Identify portfolio owner.

Possible owners include:
- ClearStack Studio
- ReadForge
- ROOT Platform
- personal
- unassigned

2. Identify required capability.

Examples:
- software -> Engineering
- market information -> Research
- acquisition/content -> Marketing
- workflows/process -> Operations
- financial analysis -> Finance
- legal/compliance -> Legal

3. Load only relevant team context.

Do not load every business context.

4. Delegate to the relevant department head.

5. Allow department head to create temporary specialists where useful.

6. Return the result to the owning portfolio team.

7. ROOT resolves cross-business conflicts.

## Efficiency Rules

- do not create duplicate permanent agents
- do not load unrelated business context
- do not delegate trivial work
- prefer one responsible department
- involve multiple departments only when necessary
- keep specialist outputs concise
